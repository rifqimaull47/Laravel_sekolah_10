## Tentang Project

Project ini dibuat sebagai tugas pembelajaran menggunakan **Laravel 10**.

Project merupakan sistem sederhana untuk mengelola data siswa, meliputi:

- Menampilkan data siswa
- Menambahkan data siswa
- Mengedit data siswa
- Menghapus data siswa
- Menyimpan data NISN dan kelas siswa
